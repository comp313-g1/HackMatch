No `PLACEHOLDER-*` file is required by the current User Manual. Established real captures for earlier stories remain under [`../wireframes/`](../wireframes/README.md) for historical repository compatibility.

When adding future captures:

1. Capture the actual running application with neutral demo data.
2. Prefer a full-window product view; use a lossless UI crop only when it prevents unrelated private data from appearing.
3. Never fabricate controls, reconstruct a screen, or expose credentials, OTPs, tokens, private emails, or developer tools.
