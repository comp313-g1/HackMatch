# Screenshot placeholders

Image paths referenced from `docs/user_manual.md` use filenames like:

`PLACEHOLDER-us-026-figure-26-1-queue.png`

Until a real product capture exists:

1. Capture the UI described by the figure caption in the user manual.
2. Save the PNG here using the exact placeholder filename (or update the markdown path).
3. Prefer full-window product UI; do not invent controls that are not in the app.

Stories with placeholder figures in v2.1 include US-001–US-006, US-011–US-013, US-015, US-017–US-020, US-022, **US-026**, and **US-027**.
